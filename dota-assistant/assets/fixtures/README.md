# Тестовые фикстуры

`match_hud_1920x1080.png` — **синтетический** кадр 1920×1080: герой игрока, союзники и противники в топ-баре, два предмета в инвентаре.

Это не скриншот реальной Dota 2. Нужен, чтобы проверить ROI + template matching и статус-панель без игры.

Пересобрать иконки и фикстуру:

```powershell
python tools\generate_fixtures.py
```

Ожидаемый результат: `match_hud_expected.json` (герой `pudge`, союзники, противники, предметы `blink_dagger` и `bottle`).
