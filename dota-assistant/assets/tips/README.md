# Правила советов (V1-alpha)

Файл `rules.json` — локальная база mid-советов:

- **builds** — порядок предметов для нескольких mid-героев
- **matchups** — агрессия по паре герой/оппонент и диапазону уровней
- **phrases** — шаблонные русские фразы (`{hero}`, `{opponent}`, `{level}`, `{item}`, `{why}`)

Редактируйте JSON вручную после патчей. Сеть и LLM не используются.
